# 职场大神养成计划

[English](README.md) | **简体中文** · [先试玩](examples/start-here.zh-CN.md) · [看完整案例](examples/everyday-work-to-materials.zh-CN.md) · [看实际测试](tests/kpi-session-report.zh-CN.md)

## 工作做得好，却说不清自己的价值？

**把零碎日常整理成真实成果，再写成你需要的工作材料。**

![卡通示意：从杂乱工作记录，到梳理真实贡献，再到清晰的工作材料](assets/illustrations/work-to-accomplishments.png)

催进度、核数据、答疑、处理异常……忙了一周，最后只写出“做了一些杂事”？这个 Skill 帮你找出自己承担的责任、解决的问题和具体交付，让别人看懂你的贡献。

**日常工作记录 → 真实贡献 → 按用途生成材料。** 没有KPI表、漂亮数字或完整履历，也能开始。

它是加载在AI工具中的工作表达助手，提供文字草稿与证据提示。适合认真做事、但不擅长总结和表达的人。

## 能帮你做什么？

| 你现在的需要 | 可以得到什么 |
| --- | --- |
| “我做了很多杂事，怎么说清楚？” | 按主题归纳的真实贡献，区分个人职责、团队结果和未完成事项 |
| “领导要周报、月度总结。” | 清晰的工作摘要、交付与待处理事项，减少流水账 |
| “这些工作怎么写进KPI自评？” | 对应实际指标的自评正文与必要证据缺口；要简短就先给一段，需要详细再展开表格 |
| “我要做述职。” | 六部分材料：职责、行动、成果、个人成长、工作改进、已确认的下一步；篇幅比例可调整 |
| “我要准备晋升、简历或面试。” | 根据目标选择真实经历，讲清个人贡献和依据 |
| “我想练练怎么和领导说。” | 一轮一轮的沟通陪练，可以暂停求助 |

想聊工作困境、复盘、吐槽或探索职业方向，也可以直接说。角色测试和趣味称号按需选择，不是开始整理工作的前置步骤。

## 怎么用？先说几件事，再选用途

![卡通示意：贴出工作便笺，和助手核对事实，再选择报告用途](assets/illustrations/three-step-start.png)

**1. 开始。** 安装加载后说：

```text
开启职场大神养成计划。
```

**2. 贴记录。** 随便说几件最近做的事，先得到可用的成果表达，不用先填问卷：

```text
用 $career-growth-plan 帮我整理这周工作：
催三个组交资料，合并了一份周报；
发现5处数字对不上，找负责人改好了；
把系统常见问题写成FAQ发到群里，不知道有没有人看。
```

**3. 按用途改写。** 核对事实后，继续说其中一种即可：

- “写成给领导看的简短周报。”
- “按这几个指标写一段KPI自评，没依据的别写达标。”
- “整理成六部分述职，下一步计划先让我确认。”

同一份记录可以连续改写，不必每次重新介绍自己。用途已经明确时，也可以一开始就说明。

**还没安装？** [复制独立试玩提示词](examples/start-here.zh-CN.md)，或先看[首次使用对话](examples/first-session.zh-CN.md)。安装方法见下方。

## 最后会得到什么效果？

| 你随手写的记录 | 整理后的真实成果表达 |
| --- | --- |
| “催三个组交资料，合并周报，找负责人改了5处对不上的数字。” | “协调三个组完成资料收集与周报汇总，核对发现5处数据差异，并联系负责人完成修正。” |
| “同事总问怎么用系统，写了FAQ发群里，不知道有没有人看。” | “回应同事的系统使用问题，将常见问题整理为FAQ并分享，供团队查阅。” |

*以上为虚构示例。表达变清楚，不等于自动证明按时交付、效率提升或FAQ被使用。*

你能带走一份**可以核对、修改并使用的材料初稿**，知道自己的贡献在哪里，以及哪些结论还缺依据。

- 不把参与写成主导，不把团队成果全算给个人。
- 没有前后经历，不编个人成长；有FAQ交付，也不自动声称流程效果提升。
- 尚未确认的下一步建议留在正文外；未确认结果、未达标和待处理事项如实保留。

正式使用前请核对事实。不承诺升职、加薪、录用或绩效评分变化。

## 安装与开始使用

这是一个以指令为主的 Agent Skill，**不是独立 App**。需要在能加载 Skill 的 AI 工具中使用。基础体验使用文字和 Markdown 卡片，不保证可点击按钮或动画。Skill 本身不要求配置 API Key、服务器或额外运行环境；AI 工具自身的账号和使用费用仍然适用。保存档案需要工具具备文件读写能力。

### 在 Codex 中使用

让内置安装器安装：

```text
用 $skill-installer 安装这个仓库根目录中的 Skill：
https://github.com/Olandooooes/career-growth-plan
```

安装后可以直接说：

```text
用 $career-growth-plan 帮我把日常工作整理成真实成果。
最近做了这些事：……
```

在安装了 Git 的 macOS/Linux 上，也可以手动克隆到 Codex 文档中的用户 Skill 目录：

```sh
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/Olandooooes/career-growth-plan.git \
  "$HOME/.agents/skills/career-growth-plan"
```

**选择一种安装方式即可。**已有安装请更新原位置，不要重复安装。旧版或定制工具可能使用其他目录；当前发现位置以[官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)为准。如果未出现在列表中，可以重启工具。

### Claude Code

已安装Claude Code和Git时，个人安装可在macOS/Linux终端运行：

```sh
mkdir -p "$HOME/.claude/skills"
git clone --depth 1 https://github.com/Olandooooes/career-growth-plan.git \
  "$HOME/.claude/skills/career-growth-plan"
```

Windows PowerShell：

```powershell
New-Item -ItemType Directory -Force "$HOME/.claude/skills" | Out-Null
git clone --depth 1 https://github.com/Olandooooes/career-growth-plan.git "$HOME/.claude/skills/career-growth-plan"
```

也可下载仓库ZIP并解压，将完整文件夹命名为 `career-growth-plan`，放入个人目录 `~/.claude/skills/`；仅供当前项目使用则放入该项目的 `.claude/skills/`。确认 `career-growth-plan/SKILL.md` 存在且辅助目录完整。在Claude Code新会话输入 `/career-growth-plan`，再贴工作记录；不要照搬Codex的 `$` 调用语法。已有安装请更新原目录，不重复克隆。

依据：[Claude Code官方Skills文档](https://code.claude.com/docs/en/skills)。

### 千问办公（QwenWork）

1. 在本仓库选择 **Code → Download ZIP** 并解压，确认解压目录内直接包含 `SKILL.md`、`references/`、`guides/` 等文件。
2. 在千问办公的 **扩展 → 技能 → 安装技能／添加** 中，按界面选择Skill文件和辅助文件；若要求ZIP，将该目录内的内容压缩，确保ZIP打开就能看到 `SKILL.md`，不要只上传单个入口而漏掉参考文件。
3. 安装后，在对话输入 `/` 选择 `career-growth-plan`，或直接说：

```text
使用 career-growth-plan 技能，帮我把以下日常工作整理成真实成果：……
```

这里指千问办公客户端，不将普通千问聊天、百炼和专家套件的入口混用。没有导入权限或无法识别时，可先用下方复制提示词方式体验。

依据：[千问办公官方技能说明](https://help.aliyun.com/zh/qwenwork/skills)、[阿里云的千问办公与WorkBuddy接入示例](https://docs.rag.bailian.aliyun.com/cookbook/office-agent)。

### WorkBuddy

1. 下载并解压本仓库，保留根目录中的 `SKILL.md` 与辅助目录。
2. 打开 **技能 → 添加技能 → 上传技能**，导入解压后的Skill文件夹；若界面要求ZIP，按上一节方法打包为根目录有 `SKILL.md` 的技能包。
3. 在「已安装」确认 `career-growth-plan` 已启用，再新建任务说：

```text
使用 career-growth-plan 技能。开启职场大神养成计划，先帮我整理最近的工作。
```

本项目未确认已上架WorkBuddy或SkillHub市场，不能保证搜索名称就能找到；因此优先说明本地导入方式。具体菜单名称随客户端版本变化。

依据：[WorkBuddy官方技能说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)、[阿里云接入示例](https://docs.rag.bailian.aliyun.com/cookbook/office-agent)。

### 豆包，以及没有原生Skill入口的平台

本项目暂未核实豆包可安装此仓库的原生Skill入口。可以在[豆包](https://www.doubao.com/)新建普通对话，体验工作整理方法：

1. 打开[中文独立试玩提示词](examples/start-here.zh-CN.md)，复制「日常工作整理成真实成果」对应代码块，粘贴发送；不只发送GitHub链接。
2. 贴几件日常工作，核对助手是否保留你的职责和未知结果。
3. 再说“写成简短周报”“写一段KPI自评”，或“整理成六部分述职，计划先让我确认”。如试玩代码块未包含所需述职细则，可补充个人成长需要前后证据、改进效果不能推断、计划确认前不进正文。

**复制提示词是当前对话体验，不等于安装完整Skill**：不会自动加载仓库参考文件，也不保证记忆、文件保存或与原生加载相同的表现。换新对话时重新粘贴。各平台可先用相同的虚构工作记录试一轮，再核对草稿。

### 安装后怎么确认？以后怎么更新？

- **核对文件：**安装目录应直接包含 `SKILL.md`，以及 `references/`、`guides/`、`examples/`、`agents/` 等随仓库提供的辅助文件。不要把 `career-growth-plan-main/` 又套在同名技能目录内，也不要只下载一个 `SKILL.md`。
- **核对调用：**Codex用 `$career-growth-plan`；Claude Code用 `/career-growth-plan`；千问办公和WorkBuddy优先从已安装列表选择，或指名使用，不假设它们都识别 `$`。如果没出现，先检查目录层级、启用状态和客户端权限，再新开会话或重新加载。
- **做一轮小验证：**给几条虚构工作记录，确认先得到真实贡献；再要求“简短KPI自评”，检查不编造达标率、不给未经确认的计划。能回答不等于已经证明按完整Skill加载，可同时检查客户端显示的技能状态。
- **更新原安装位置：**Git克隆方式在终端对原目录执行 `git -C "实际安装目录/career-growth-plan" pull --ff-only`；若有本地修改或拉取失败，先处理提示，不删除重装。文件夹／ZIP导入方式重新下载仓库，按客户端的同名技能更新流程导入，避免并存多份。提示词体验则重新复制最新代码块。

安装说明参考了[HowToLiveBetter的life-decision-guide说明](https://github.com/eternity4719/HowToLiveBetter/blob/main/skills/life-decision-guide/README.md)中“按宿主区分目录与调用方式、共用一套规则”的做法；本项目有按需读取的辅助文件，因此采用完整目录安装，不能照搬仅下载单个入口文件的方法。平台步骤仍以各自官方文档为准。

### 其他支持 Skill 的工具

按相应工具的安装方式加载，保留 `SKILL.md`、`references/` 和 `agents/` 的完整结构。尚未逐一验证所有工具的原生集成。只想体验一次，也可以让 AI 阅读本地项目中的 `SKILL.md` 和相关参考文件；这不等于完成安装，也不会自动产生永久记忆。

## 中英文，共用一套能力

核心规则用英文维护，但助手默认跟随你的语言，也接受明确指定：

```text
开启职场大神养成计划。帮我整理最近的工作，为转正述职做准备。
```

```text
我们用中文讨论，但最后帮我写成英文面试故事。
```

职场术语需要符合你的实际环境；不能因为你说中文就假设所在国家或公司晋升制度。实际语言表现受所用模型影响，需要在使用中验证。

## 档案由你掌握

当你要求保存且有文件工具时，助手会在适合存放私人资料的工作区维护 Markdown 档案，与这个公开项目分开，写入后告知实际路径。已有的 `职业成长档案/` 会继续沿用，不因切换语言而新建一套记录。

没有文件工具时，会提供可复制文本并明确说明未保存。当前没有后台自动收集、自动提醒或账号同步。本 Skill 不增加遥测或后台服务，但对话内容仍按你使用的 AI 工具的数据设置处理；分享前请自行检查、脱敏公司信息。

没有稳定记忆也能继续：说“给我一张接力卡”，拿到自己认可的背景、方向、已尝试的动作和待聊问题。下次贴回去即可，不会假装已经保存。
