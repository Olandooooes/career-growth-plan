# 职场大神养成计划

[English](README.md) | **简体中文**

### 看看你每天忙的这些事，正在把你变成什么样的人。

聊几个有趣的问题，解锁你的职场角色，看看这份工作的得失，再选择自己的下一步。想吐槽、庆祝、解决难题，或者认真准备述职和跳槽，都可以来聊。

**英文名：Career Growth Companion** · `career-growth-plan` · [MIT](LICENSE)

> **职场角色：跨部门混乱驯服师**
>
> **名义职业：**运营。**实际日常：**把不同团队的理解接起来。
>
> **露出的本领：**你把一次需求分歧整理成了可以逐项确认的问题。
>
> **当前困境：**临时协调占了很多时间，你希望有机会完整负责一件事。
>
> **可选下一步：**讨论一个范围明确的小项目，以及它应该替换哪些现有工作。

*虚构角色卡示例：不是心理测评或真实职务，观察需要与你的实际经历核对。*

## 先玩一次，不用安装

**[复制提示词，开始中文试玩 →](examples/start-here.zh-CN.md)**

选一个你现在想试的：测测职场角色、把工作翻译成「人话 / 江湖 / 专业」三个版本、练习一句不敢跟领导说的话。复制到你常用的 AI 对话即可；这是轻量试玩，完整 Skill 还提供复盘、材料整理和本地档案能力。

## 今天从哪里开始？

| 入口 | 可以这样说 | 会发生什么 |
| --- | --- | --- |
| 认识自己 | “开启职场大神养成计划，看看我的职场角色。” | 轻量趣味问答 → 可修改的角色卡 → 工作处境解读 → 自己选方向 |
| 聊聊今天 | “今天想吐槽，先别给我安排计划。” | 根据你的需要倾听、庆祝、解题或复盘，不强迫记日志 |
| 选择下一步 | “我想争取一个完整项目，但总在救火。” | 结合现实约束选一个可尝试的动作，之后回看结果 |

**两个随时能用的小工具：**

- **工作翻译器：**“我就是天天催人交东西，帮我说清这份工作的价值。”趣味版可以夸张，专业版守住事实。
- **职场对话陪练：**“你演我的领导，我想练习怎么争取一个项目。”一次聊一轮，可以暂停求助，最后得到一个改进点和被拒绝时的退路。

也支持直接说“明天就要述职，帮我整理材料”，跳过问卷。认真模式下可以关闭趣味称号。

**养成感来自真实变化：**从需要别人带着处理，到自己识别分歧、组织确认；从反复救火，到建立可复用的方法。没有依据时不编造成长，不靠签到、虚构分数或断更惩罚制造压力。

## 安装与开始使用

这是一个以指令为主的 Agent Skill，**不是独立 App**。需要在能加载 Skill 的 AI 工具中使用。基础体验使用文字和 Markdown 卡片，不保证可点击按钮或动画。Skill 本身不要求配置 API Key、服务器或额外运行环境；AI 工具自身的账号和使用费用仍然适用。保存档案需要工具具备文件读写能力。

### 在 Codex 中使用

让内置安装器安装：

```text
用 $skill-installer 安装这个仓库根目录中的 Skill：
https://github.com/Olandooooes/career-growth-plan
```

安装后可以直接说：

```text
用 $career-growth-plan 开启职场大神养成计划。
先问我几个有趣的问题，帮我看看我的职场角色。
```

在安装了 Git 的 macOS/Linux 上，也可以手动克隆到 Codex 文档中的用户 Skill 目录：

```sh
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/Olandooooes/career-growth-plan.git \
  "$HOME/.agents/skills/career-growth-plan"
```

**选择一种安装方式即可。**已有安装请更新原位置，不要重复安装。旧版或定制工具可能使用其他目录；当前发现位置以[官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)为准。如果未出现在列表中，可以重启工具。

### 其他支持 Skill 的工具

按相应工具的安装方式加载，保留 `SKILL.md`、`references/` 和 `agents/` 的完整结构。尚未逐一验证所有工具的原生集成。只想体验一次，也可以让 AI 阅读本地项目中的 `SKILL.md` 和相关参考文件；这不等于完成安装，也不会自动产生永久记忆。

## 中英文，共用一套能力

核心规则用英文维护，但助手默认跟随你的语言，也接受明确指定：

```text
开启职场大神养成计划。帮我整理最近的工作，为转正述职做准备。
```

```text
我们用中文讨论，但最后帮我写成英文面试故事。
```

职场术语需要符合你的实际环境；不能因为你说中文就假设所在国家或公司晋升制度。实际语言表现受所用模型影响，需要在使用中验证。

## 档案由你掌握

当你要求保存且有文件工具时，助手会在适合存放私人资料的工作区维护 Markdown 档案，与这个公开项目分开，写入后告知实际路径。已有的 `职业成长档案/` 会继续沿用，不因切换语言而新建一套记录。

没有文件工具时，会提供可复制文本并明确说明未保存。当前没有后台自动收集、自动提醒或账号同步。本 Skill 不增加遥测或后台服务，但对话内容仍按你使用的 AI 工具的数据设置处理；分享前请自行检查、脱敏公司信息。

没有稳定记忆也能继续：说“给我一张接力卡”，拿到自己认可的背景、方向、已尝试的动作和待聊问题。下次贴回去即可，不会假装已经保存。

## 项目状态与参与方式

如果试玩帮你说清了一件工作、练好了一次对话，欢迎给仓库点一个 **Star**，方便以后找到它。也欢迎把试玩链接分享给正遇到同样问题的人；无需 Star 即可使用全部内容。

目前是早期版本。案例展示预期行为，不是实测成绩、用户评价或职业结果证明；不承诺升职、录用或薪资变化。

**[告诉我们哪一句让你觉得“懂我”，或哪一步让你想退出](https://github.com/Olandooooes/career-growth-plan/issues/new?template=experience.yml)。** 只提交你愿意公开的脱敏内容，无需提供公司、薪资或私人档案。

欢迎用**中文或英文**提交 Issue 和 Pull Request。最有帮助的反馈是：脱敏后的输入、实际输出和你期待的结果。不要上传真实私人职业档案。修改行为或安装步骤时同步更新两份 README，核心规则保持一份，不另建中英文功能分支。
